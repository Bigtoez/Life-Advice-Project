# 🌤️ It's Complicated - Complete UI Redesign

## Overview
Stunning new sky/cloud theme inspired by Simpson's opening. Floating clouds, cartoon widgets, sleek chat.

## Pages Created

**1. Landing Page** (`index.tsx`)
- "It's Complicated" floating animated letters
- Click to trigger 2-second wind animation blowing letters away
- Sky gradient background with cloud patterns
- Fredoka brand font with gradient text effect

**2. Offerings Page** (`offerings.tsx`)
- 3 cartoon octagon cloud widgets
- Instagram, TikTok, Chat Sessions cards
- Hover effects with emoji animations
- Pulsing background clouds

**3. Sessions Menu** (`sessions-menu.tsx`)
- 4 coaching session types as cloud cards
- The Pattern, After Fight, Breakup, Group
- Each with emoji, title, description, price, duration
- Scale hover effects, professional layout

**4. Chat Session** (`session/[type].tsx`)
- Sleek centered chat interface
- User messages right-aligned (sky-blue)
- AI messages left-aligned (white + border)
- Header with title + timer
- Rounded pill input, send button
- Loading dots animation

## Design System

**Colors**: Sky blues, cyan, white with 2-4px borders  
**Font**: Fredoka (Google Fonts) - friendly, cloud-like  
**Shapes**: Octagon clouds, rounded pills, 2xl borders  
**Animations**: Wind blow, bouncing, scaling, fading
